# ربط قاعدة بيانات حقيقية (Supabase)

> بعد هذه الخطوات، تصبح إضافة/تعديل/حذف الأبطال من لوحة الإدارة **دائمة فعلياً** —
> لا تختفي بعد إعادة تحميل الصفحة، ولا حتى بعد نشر تحديث جديد للموقع.

جربنا Supabase تحديداً لأن بياناتك (أبطال + كاونترات) علائقية بامتياز، وهو مبني على PostgreSQL،
وله باقة مجانية سخية تكفي هذا المشروع بالكامل، ويعمل مباشرة من صفحة HTML ثابتة بلا أي خادم وسيط.

---

## الخطوة ١ — أنشئ مشروع Supabase (مجاني، ٥ دقائق)

1. ادخل [supabase.com](https://supabase.com) وسجّل الدخول (يمكن عبر GitHub مباشرة).
2. اضغط **New Project**. اختر اسماً (مثلاً `landofdraft`)، وكلمة سر لقاعدة البيانات (احفظها جانباً)، والمنطقة الأقرب لك.
3. انتظر ~٢ دقيقة حتى يكتمل تجهيز المشروع.

## الخطوة ٢ — أنشئ الجداول

1. من القائمة الجانبية اختر **SQL Editor**.
2. افتح ملف `supabase_schema.sql` المرفق هنا، انسخ محتواه بالكامل، الصقه، واضغط **Run**.
   هذا ينشئ جدولي `heroes` و`counters` مع سياسات الحماية (RLS): القراءة عامة للجميع، والكتابة محصورة بمستخدم مسجَّل دخول فعلياً فقط.
3. افتح ملف `supabase_seed.sql` (مولَّد تلقائياً من بيانات موقعك الحالية: ١٣٣ بطلاً و٢٧٨ كاونتر)، الصقه في SQL Editor، واضغط **Run** مرة أخرى.
4. تحقّق: من **Table Editor** يجب أن ترى ١٣٣ صفاً في `heroes` و٢٧٨ صفاً في `counters`.

## الخطوة ٣ — أنشئ حساب الإدارة

1. من القائمة الجانبية اختر **Authentication → Users**.
2. اضغط **Add User → Create New User**.
3. أدخل بريدك الإلكتروني وكلمة مرور قوية. فعّل **Auto Confirm User** حتى لا يحتاج تأكيداً بالبريد.
4. هذا هو الحساب الذي ستستخدمه لتسجيل الدخول إلى لوحة الإدارة على موقعك — **ليس** `admin`/`2026` القديمين.

## الخطوة ٤ — انسخ مفاتيح الاتصال

1. من **Project Settings → API**.
2. انسخ قيمتين فقط:
   - **Project URL** (يشبه `https://xxxxx.supabase.co`)
   - **anon public key** (سطر طويل يبدأ بـ `eyJ...`)

> هاتان القيمتان مصمَّمتان لتكونا علنيتين داخل كود الموقع نفسه — الحماية الحقيقية تأتي من سياسات RLS وحساب الدخول، لا من إخفاء هذين المفتاحين.

## الخطوة ٥ — الصقهما في `index.html`

افتح `index.html`، ابحث عن هذا السطر قرب بداية الكود:

```js
const SUPABASE_URL = 'PASTE_YOUR_SUPABASE_URL_HERE';
const SUPABASE_ANON_KEY = 'PASTE_YOUR_SUPABASE_ANON_KEY_HERE';
```

استبدل القيمتين بما نسخته في الخطوة السابقة، ثم:

```bash
git add index.html
git commit -m "ربط قاعدة بيانات Supabase"
git push
```

سينشر Vercel نسخة جديدة تلقائياً خلال ثوانٍ. من هذه اللحظة:

- الموقع يقرأ الأبطال والكاونترات من قاعدة البيانات مباشرة عند كل زيارة.
- لوحة الإدارة تطلب **بريدك الإلكتروني وكلمة المرور** الحقيقيين (لا الرقم السري القديم).
- أي إضافة أو تعديل أو حذف بطل، أو رفع صورة، يُكتب في Supabase فوراً ويبقى محفوظاً للأبد.

---

## ماذا لو لم أفعل شيئاً من هذا؟

الموقع يستمر بالعمل تماماً كما هو الآن — بيانات محلية داخل الكود، ولوحة إدارة بدخول `admin`/`2026` مؤقتة الأثر.
لا شيء ينكسر؛ الاتصال بقاعدة البيانات **اختياري بالكامل**.

## ملاحظة عن الأمان

الآن الكتابة تتطلب حساب Supabase Auth حقيقياً يتحقّق منه خادم Supabase نفسه — وهذا أمان حقيقي، بخلاف
البوّابة السابقة (`admin`/`2026`) التي كانت مجرّد حاجز مكتوب في الكود يراه أي شخص من "عرض المصدر".
مع ذلك: أي شخص يملك بريد وكلمة مرور الحساب الذي أنشأته في الخطوة ٣ يستطيع التعديل — فاحفظهما جيداً ولا تشاركهما.
